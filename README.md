📌 Overview

This repository contains a collection of basic to intermediate Java programs created for learning and practicing core programming concepts. It includes a variety of programs such as pattern printing, array operations, mathematical problems, and simple mini-projects.

The purpose of this repository is to strengthen problem-solving skills, understand Java fundamentals, and build a strong foundation for Data Structures and Algorithms (DSA).
